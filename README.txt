# Gelana Adugna — Research Profile Website

This is a responsive, static personal academic website. It can be hosted for free with GitHub Pages. You do not need to install a website builder or know programming to publish it.

## Files
- `index.html` — all website text, sections, publication records, and links
- `styles.css` — colors, layout, typography, and mobile responsiveness
- `Gelana_Adugna_CV.pdf` — add your own CV PDF here before publishing (not included yet)

## Before publishing
1. Open `index.html` in a text editor such as Notepad or Visual Studio Code.
2. Replace `YOUR_EMAIL@example.com` with your professional email address.
3. Replace LinkedIn, Google Scholar, ResearchGate, ORCID, and GitHub placeholder URLs with your real profile links.
4. Check every publication title, author list, journal, date, and DOI.
5. Add your PDF CV in this folder and name it exactly `Gelana_Adugna_CV.pdf`.
6. Add a professional headshot if you want one. The current hero uses a CSS illustration and does not require an image.
7. Remove any content you do not want public. Do not publish personal phone numbers, private documents, or project material you do not have permission to share.

## Publish free with GitHub Pages
You already have a GitHub account and Git installed, so GitHub Pages is a suitable option.

### Easiest method (no terminal commands)
1. Sign in to GitHub and create a new repository named `gelana-adugna.github.io` (replace `gelana-adugna` with your actual GitHub username).
2. Set the repository to **Public**. Choose to create the repository.
3. In the repository, choose **Add file → Upload files**.
4. Upload `index.html`, `styles.css`, and your `Gelana_Adugna_CV.pdf` file. You may also upload the `assets` folder if you add images later.
5. Commit the files to the repository's `main` branch.
6. Open **Settings → Pages**. Under the build/deployment section, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
7. Wait a few minutes and open `https://YOUR-GITHUB-USERNAME.github.io/`.

### If you want to use a repository with another name
Create a public repository such as `research-profile`, upload the files, and enable GitHub Pages in Settings → Pages. The URL will normally be `https://YOUR-GITHUB-USERNAME.github.io/research-profile/`.

## Updating later
When you have a new publication or CV, edit the relevant text/file and upload the replacement to GitHub. GitHub Pages will publish the changes automatically after the commit and deployment finish.

## Important
The website is a starter draft based on available professional information. Verify all biographical details and publication metadata before publishing. This template does not collect visitor data and has no contact form; email and profile links are direct links.
